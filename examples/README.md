# Sample data

`sample_scan_latest.csv` and `sample_history/` are real output -- not synthetic fixtures. They were
generated by `scripts/verify_against_real_data.py` from 66 real NSE trading days originally captured by
the old StockGPT bot, run back through this repo's new scoring and backtest engines. See the "Verified
against real data" section of the top-level README for what that run found.

They exist here so the dashboard and Strategy Lab work the moment you clone this repo, before
`daily_pipeline.yml` has run even once. To use them locally:

```bash
mkdir -p data/scans data/history
cp examples/sample_scan_latest.csv data/scans/latest_scan.csv
cp -r examples/sample_history/* data/history/
streamlit run dashboard/app.py
```

This data is real but stale by definition -- it's a snapshot of a specific 66-day window, not live
prices. Once GitHub Actions starts running `daily_pipeline.yml` against your new repo, `data/scans/` and
`data/history/` will be overwritten with live data on schedule, and `data/history/` will keep
accumulating real days going forward instead of the ones frozen here.
